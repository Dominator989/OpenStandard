# Roadmap

## Phase 1: Reliable scan

- Accept one public URL
- Capture page metadata and a screenshot
- Run a small, documented set of checks
- Store a scan and its findings locally

## Phase 2: Useful report

- Add severity and confidence
- Show affected HTML and remediation hints
- Export an accessible HTML report
- Compare two scans

## Phase 3: Agency workflow

- Projects and team members
- Client branding
- Scan history
- Review and status workflow
